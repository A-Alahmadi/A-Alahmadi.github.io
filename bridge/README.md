# الجسر (bridge-maestro)

حزمة جاهزة لتشغيل Claude Code وشات جي بي تي معاً من طرفية واحدة على جهازك.

## التثبيت على ويندوز (5 دقائق)
1. `npm i -g @openai/codex` ثم `codex login` (يفتح المتصفح، لا تلصق أي مفتاح في الطرفية).
2. انسخ مجلد `bridge` إلى `%USERPROFILE%\.claude\skills\bridge-maestro` (حتى يصبح `SKILL.md` داخله مباشرة).
3. من مجلد أي مشروع: `pwsh -File "$env:USERPROFILE\.claude\skills\bridge-maestro\scripts\bridge.ps1" selftest`
   المتوقع: ثلاثة أسطر تنتهي بـ "الجسر جاهز".
4. في Claude Code اكتب: `/bridge-maestro` ثم أعطه المهمة.

## على WSL أو لينكس
نفس الخطوات مع `scripts/bridge.sh`.

## الأوامر
| الأمر | يفعل |
|---|---|
| `selftest` | يفحص التثبيت وتسجيل الدخول والاتصال |
| `ask "نص"` | سؤال جديد للشريك، قراءة فقط |
| `continue "نص"` | متابعة آخر جلسة، وإن لم يدعمها الإصدار يمرر خلاصة السجل |
| `write "نص"` | تنفيذ بصلاحية كتابة، مقفل حتى تضبط `BRIDGE_ALLOW_WRITE=1` |
| `log` | آخر 40 سطراً من السجل `.bridge/transcript.md` |

متغيرات اختيارية: `BRIDGE_MODEL` لاختيار الموديل، `BRIDGE_ROOT` لتغيير مجلد العمل.

## ما تم اختباره وما لم يتم
- اختُبر منطق السكربت (تمرير stdin، السجل، قفل الكتابة، مسار الفشل) ببديل وهمي لـ Codex، لأن الاتصال الحقيقي بـ OpenAI محجوب في بيئة الإعداد.
- لم يُختبر الاتصال الفعلي. أول تشغيل حقيقي هو `selftest` على جهازك.
